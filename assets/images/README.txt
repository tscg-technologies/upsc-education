# UPSC EDUCATION - Image Assets Guide

In accordance with strict project guidelines, external photographic images are replaced by 10 dedicated CSS-based academic visual placeholders. This ensures rapid loading, responsive fidelity, and strict compliance with zero external dependencies.

## 10 Reusable CSS Image Placeholders:
1. `upsc-hero` - UPSC aspirant studying at a professional academic desk.
2. `upsc-classroom` - Modern civil services coaching classroom.
3. `upsc-faculty` - Academic faculty member teaching UPSC aspirants.
4. `upsc-library` - Academic library with books and study resources.
5. `upsc-study` - Aspirant studying with books and handwritten notes.
6. `upsc-discussion` - Group discussion among civil services aspirants.
7. `upsc-test-series` - Student attempting a written examination.
8. `upsc-current-affairs` - Newspaper, notes, and current affairs study materials.
9. `upsc-mentorship` - Faculty mentoring an aspirant.
10. `upsc-academic-environment` - Professional academic learning environment.

When replacing with actual high-resolution photography in production, replace the `.image-placeholder` elements with `<img>` tags pointing to optimized JPG/WebP assets of the exact dimensions indicated in the HTML comments.
